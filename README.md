# Automated CI/CD Deployment Pipeline

A portfolio DevOps project focused on building a production-oriented deployment workflow for a small web API.

## Project Status

🚧 In Development

The project is currently being built step by step, starting with repository setup and project foundation.

## Project Goal

The goal of this project is to demonstrate how application code can move through an automated deployment workflow:

Developer → GitHub → GitHub Actions → Docker → Ubuntu Server → Nginx → FastAPI
